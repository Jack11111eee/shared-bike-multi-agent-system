# 跨数据源一致性报告（F6-5）

本报告只做对比，不把两个数据源的结果混在同一张结果表里。每个数字仍归属于各自的数据源报告。

| 维度 | DS-XM | DS-SH |
|---|---|---|
| 订单行数 | 220675 | 102361 |
| 网格格子数 | 169 | 255 |
| 时间桶数 | 20 | 743 |
| 零借出占比 | 29.76% | 76.39% |
| 基线 MAE（借出） | 7.0754 | 0.5336 |
| 模型 MAE（借出） | 7.3755 | 0.5103 |
| 规则策略未满足请求 | 3617 | 181 |
| 优化策略未满足请求 | 3669 | 170 |
| 规则策略综合代价 | 3,788.15 | 892.88 |
| 优化策略综合代价 | 3,829.88 | 879.42 |

## 一致的结论

- 两个源都出现了明显的空间不均衡：净流出与净流入格子同时存在，风险清单的符号约定在两个源上都成立。
- 两个源的仿真都满足守恒、容量与预算约束（violations 全为 0）。
- 两个源的预测都采用同一条时间切分规则与同一套特征，方法可迁移。

## 不一致的结论

- **模型是否优于基线**：XM 上模型未能同时优于基线（借出 MAE 7.0754 → 7.3755，归还 6.9712 → 6.7322）；SH 上 LightGBM 在借出与归还两个目标上均优于基线（MAE 0.5336 → 0.5103，0.5396 → 0.5129）。XM 的时间覆盖只有 20 个时间片，这直接限制了树模型能学到的结构。
- **策略胜负**：XM 上 S-RULE 优于 S-OPT（综合代价 3788.15 → 3829.88）；SH 上 S-OPT 略优（综合代价 892.88 → 879.42）。差异来自需求密度、预测误差与容量假设的不同。
- **零值占比**：XM 1000 m 网格零借出 29.76%（169 个格子）；SH 2000 m 网格零借出 76.39%（255 个格子）。稀疏程度更高的源，其风险清单的绝对幅度也更小。

## 使用边界

任何结论只在报告明确标注的数据源上成立。不得把 XM 的结论直接外推到 SH，反之亦然；也不得把两者合并训练或合并报表。
