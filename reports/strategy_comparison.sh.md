## 共享假设（F5-3 公平性）

两策略**共享**以下全部输入与假设，唯一不同的变量是**调度决策算法**：

| 假设 | 取值 | 来源 |
|---|---|---|
| 初始库存比例 | 0.5 | 估计（D6，可配置） |
| 安全库存比例 | 0.2 | 估计（D6，可配置） |
| 每时间单元搬运预算（bikes） | 200 | 约定（D6，可配置） |
| 未满足请求惩罚 | 1 | 约定（D6） |
| 距离成本（每 bike-km） | 0.2 | 约定（D6） |
| 停放容量 | fixed | XM=电子围栏密度；SH=固定假设（无围栏数据） |
| 需求预测输入 | 同一份 forecast 文件 | F3 产物 |
| 回放需求 | 同一份历史借还计数 | F2 产物 |
| 调度时点 | 每个时间单元开始时，用该单元的预测做一次性决策 | 两策略相同 |

调度在每个时间单元开始时，用**该单元的预测**（一步预测）决定搬运，然后依次执行归还与借车请求；两策略使用完全相同的预测、库存与容量，因此差异只来自分配算法。

## 结果解读

在本回放条件下，S-OPT 的综合代价**显著更低**：综合代价 892.88 → 879.42（点估计下降 1.51%）；总差异 -13.47，95% CI [-25.31, -1.08]，n=149。

未满足请求 181 → 170，搬运距离 3559.42 → 3547.09 bike-km。

逐时间单元看：共 149 个单元，S-OPT 综合代价更低 23 个、更高 60 个、持平 66 个。
改善并非在每个单元上一致：S-OPT 的收益集中在少数单元（单次幅度较大），S-RULE 则在更多单元上略占优（单次幅度很小）。因此“总代价更低”成立，但不能表述为“每个时段都更好”。

按 F5-5，无论 S-OPT 胜出与否都如实报告，未通过调整假设制造优势。

## 守恒与容量溢出

| 指标 | S-RULE | S-OPT |
|---|---|---|
| 回放归还总数 | 28998 | 28998 |
| 因容量不足未能入库的归还（returns_overflow） | 522 | 487 |
| 初始库存 | 5100 | 5100 |
| 末期库存 | 4860 | 4884 |
| 总容量 | 10200 | 10200 |

`returns_overflow` 是回放中**超过该格子停放容量**的归还数量。这些车辆被计为溢出并从被跟踪的库存中剔除，而不是凭空消失后又被当成可用供给；两策略使用相同的溢出规则，因此不影响对比的公平性。守恒计数器（`violations`）覆盖调度搬运与借还，不含溢出，溢出单独统计，见上表与 `outputs/sim_rule.sh.json`、`outputs/sim_optimized.sh.json`。

## 局限

- 仿真只回放 F3 测试时段，窗口长度受数据时间覆盖限制（XM 仅 4 个小时片，SH 约 6 天）。
- 容量、初始库存、运力预算均为假设值，REPORT.md 的敏感性分析给出了变化后的结果。
- 未建模车辆路径（VRP），搬运成本按 bike-km 计，不区分车辆调度次数。
