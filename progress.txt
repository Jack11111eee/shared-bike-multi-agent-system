## Learnings / gotchas

- `order data.csv` and `STATION.csv` are actually XLSX files despite the extension.
- The feedback gate fingerprints every non-filtered output line, so `pytest -q`'s
  dots line counts as a "failure". The PRD feedback command was changed to
  `python3 -m pytest -q --tb=no -rf 2>&1 | grep -E "^(FAILED|ERROR)" || true`,
  which emits nothing on green and FAILED/ERROR lines on failure. The baseline was
  re-recorded after that change (the original baseline was recorded before any tests
  existed, so it only contained "no tests ran").
- The min-cost-flow planner must exclude deficit cells from the supply set; otherwise
  the solver "serves" a cell from itself with zero-distance flow and wastes the budget.

## Learnings / gotchas (Phase 2)

- `pandas` `.astype(int)` on the pivoted returns array truncates per cell; that is
  safe only because panel counts are integral. F8-2 checks the sum on every bucket,
  so a future fractional panel would fail loudly rather than silently.
- `file://` cannot `fetch()` sibling JSON (CORS), so the frame payload has to be
  inlined in each page. That is the reason for the 23 KB/page average, not a bug.
- An SVG `marker` without `markerUnits="userSpaceOnUse"` scales with `stroke-width`
  and produces arrowheads larger than the cells; both are needed to look right.
- The first version of the agent conclusion quoted a computed percentage and a
  summed total. F11-5 rejects those — every cited number must be copied verbatim
  from a tool response, so the planner now quotes only direct values.
