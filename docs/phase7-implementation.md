## 地图实际可用性

本环境高德没有加载成功。用户目前只配置了 JS Key，未配置安全码；不能仅凭本次失败断言唯一原因。已实测 OpenStreetMap 在线街道底图与网格叠加可用，离线底图也可正常切换。

地图 Web Key通过本地服务提供给浏览器，不写入静态演示包。DeepSeek密钥不进入页面。

## 仍需用户确认的展示项

内置浏览器仅允许 HTTP/HTTPS，拒绝打开 file://。没有通过其他浏览器或间接方式绕过该限制。独立演示包已完成本地资源检查，但需要用户在普通浏览器中打开确认。

本地仿真为同步计算。超时结果不作为成功评估，取消停止后续动作，但不承诺抢占正在执行的引擎。现场建议使用已经完成的真实记录回放。
